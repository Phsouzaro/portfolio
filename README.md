# Pedro Henrique — Portfolio

English-first portfolio for international backend engineering opportunities. Modern terminal aesthetic, Angular standalone components, responsive layout, EN/PT-BR toggle.

## Start

Requires Node.js 22+ and npm.

```bash
npm install
npm start
```

Build: `npm run build`. Static output is in `dist/portfolio/browser`.

## Before publishing

- Replace the LinkedIn placeholder (`https://www.linkedin.com/`) with the real profile URL.
- Review copy and professional claims.
- Add real project screenshots and a dedicated Atlas case study in the next iteration.
- Configure hosting (Cloudflare Pages or Vercel) to build with `npm run build` and publish `dist/portfolio/browser`.

This starter does not include a backend, analytics, trackers, or a contact form.
